## ?? Componentes

### 1?? **IValidacionRule** (Interfaz)
Define el contrato que toda regla debe cumplir:
- `NombreRegla`: Identificador único
- `Descripcion`: Documentación de qué valida
- `Tipo`: Error o Advertencia  
- `Orden`: Secuencia de ejecución
- `ValidarAsync()`: Lógica de validación

### 2?? **ValidacionRuleBase** (Clase Abstracta)
Proporciona funcionalidad común:
- Manejo de excepciones
- Template method pattern
- Helper `CrearDetalle()` para mensajes consistentes

### 3?? **Reglas Concretas** (Implementaciones)
Cada regla:
- Extiende `ValidacionRuleBase`
- Define su query SQL específica
- Retorna lista de `DetalleValidacionDto`

### 4?? **ValidacionExecutor** (Orquestador)
- Recibe todas las reglas vía DI
- Ejecuta en orden configurado
- Consolida resultados
- Expone método de documentación

## ?? Inyección de Dependencias

```csharp
// Startup.cs
services.AddScoped<IValidacionRule, ValidarFormatoCuilRule>();
services.AddScoped<IValidacionRule, ValidarCuilDuplicadoRule>();
services.AddScoped<IValidacionRule, ValidarRemuneracionPositivaRule>();
services.AddScoped<IValidacionRule, ValidarPeriodoFuturoRule>();

services.AddScoped<ValidacionExecutor>(provider =>
{
    var reglas = provider.GetServices<IValidacionRule>();
    return new ValidacionExecutor(reglas);
});
```

## ?? Ejemplo de Implementación

```csharp
public class ValidarCuilDuplicadoRule : ValidacionRuleBase
{
    public override string NombreRegla => "CUIL_DUPLICADO";
    public override string Descripcion => "Verifica CUILs únicos";
    public override TipoValidacion Tipo => TipoValidacion.Error;
    public override int Orden => 10;

    protected override async Task<List<DetalleValidacionDto>> 
 EjecutarValidacionAsync(IDbConnection connection, long idArchivo)
    {
    var sql = @"
      SELECT CUIL, COUNT(*) AS Cantidad, MIN(ROWNUM) AS Linea
            FROM USUARIO.TMP_NOV_DDJJ_PREV
     GROUP BY CUIL
            HAVING COUNT(*) > 1";

      var duplicados = await connection.QueryAsync<Duplicado>(sql);
        
   return duplicados.Select(d => CrearDetalle(
       $"CUIL {d.Cuil} duplicado {d.Cantidad} veces",
  d.Linea,
          1
        )).ToList();
    }
}
```

## ? Ventajas del Diseño

| Aspecto | Beneficio |
|---------|-----------|
| **Extensibilidad** | Nueva regla = nueva clase + 1 línea en Startup |
| **Mantenibilidad** | Cada regla es independiente y autodocumentada |
| **Testabilidad** | Mockear IDbConnection para tests unitarios |
| **Transparencia** | Endpoint GET /reglas-validacion lista todas |
| **Flexibilidad** | Control de orden, tipo (error/advertencia) |
| **Robustez** | Excepciones aisladas por regla |

## ?? Agregar Nueva Regla (3 pasos)

### Paso 1: Crear la regla
```csharp
// Validaciones/Rules/ValidarMiReglaRule.cs
public class ValidarMiReglaRule : ValidacionRuleBase
{
    public override string NombreRegla => "MI_REGLA";
    public override string Descripcion => "Validación custom";
    public override TipoValidacion Tipo => TipoValidacion.Error;
    
    protected override async Task<List<DetalleValidacionDto>> 
    EjecutarValidacionAsync(IDbConnection conn, long id)
    {
        // Tu SQL aquí
        var resultados = await conn.QueryAsync<MiDto>("SELECT ...");
        return resultados.Select(r => CrearDetalle(...)).ToList();
    }
}
```

### Paso 2: Registrar en DI
```csharp
// Startup.cs
services.AddScoped<IValidacionRule, ValidarMiReglaRule>();
```

### Paso 3: ¡Listo! ??
La regla se ejecutará automáticamente.

## ?? Patrones Aplicados

- ? **Chain of Responsibility**: Múltiples handlers procesan la request
- ? **Template Method**: ValidacionRuleBase define esqueleto
- ? **Strategy**: Cada regla es una estrategia intercambiable
- ? **Dependency Injection**: Desacoplamiento total
- ? **Open/Closed Principle**: Abierto a extensión, cerrado a modificación
